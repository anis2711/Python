# 🐾 Gestion d'une association de protection animale

## 📖 Description

Ce projet est un exercice réalisé en **Python**.

Le programme permet de gérer les animaux d'une association de protection animale grâce à un menu interactif dans le terminal.

## 🎯 Fonctionnalités

- Afficher la liste des animaux
- Ajouter un animal
- Supprimer un animal
- Modifier le statut d'adoption d'un animal
- Afficher l'inventaire des espèces animales
- Quitter le programme

## 📋 Menu

```text
=== MENU PRINCIPAL ===

1. Voir les animaux
2. Faire l'inventaire des espèces animales
3. Ajouter un animal
4. Retirer un animal
5. Changer le statut d'adoption d'un animal
0. Quitter
```

## 🛠️ Technologies utilisées

- Python 3

